# Architecture decision records

The [Week 10 architecture](../architecture.md) records the initial layer, Home3D, and local backend decisions. The [Week 13 demo spec](https://github.com/bagtyyarkovusov/smart-home/issues/2) defines the first release slice.

When a later decision changes an architectural choice, add a numbered ADR with its status, context, decision, alternatives, and consequences. Link the new record here.
